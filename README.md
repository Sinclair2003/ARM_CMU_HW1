# Assignment 1 Workspace

## Folder Layout

- `submission/`: final report draft files for editing/submission.
- `notebook/`: main assignment notebook and equivalent script for Colab/local runs.
- `tools/`: functional helper programs used to generate report files.
- `source_materials/`: course-provided starter script and ticker appendix.
- `misc/`: unrelated or non-assignment files that were in the workspace.

## Main Files

- `submission/assignment1_report_draft.docx`: report draft in DOCX format.
- `submission/assignment1_report_draft.md`: same report content in Markdown.
- `submission/assignment1_report_draft.pdf`: PDF version for easier viewing/submission.
- `notebook/pairs_trading_colab.ipynb`: notebook to upload/run in Google Colab.
- `notebook/pairs_trading_colab.py`: script version of the notebook.
